# CS294 Systems Modeling and Simulation

## Overview

I developed an understanding of systems modeling and simulation focusing on ordinary differential equations, stochastic processes, sensitivity analysis, and ocean circulation simulation. This collection demonstrates my ability to translate complex physical systems into computational models and conduct rigorous numerical analysis.

## Learning Objectives

I gained proficiency in:
- Implementing and analyzing ordinary differential equations (Lorenz systems, chaotic dynamics)
- Formulating and numerically solving stochastic differential equations (Euler-Maruyama, Milstein methods)
- Conducting sensitivity analysis on complex hydrodynamic models
- Understanding noise models (white noise, colored noise, Levy processes)
- Model validation and comparison against observational data

## Coding Exercises

### Exercise 1: ODE Modeling
I implemented the Lorenz attractor system using both agent-based modeling (NetLogo) and system identification (Vensim) to understand chaotic behavior and model sensitivity to initial conditions.

### Exercise 2: Stochastic Processes
I studied stochastic differential equations and their numerical solution methods, comparing different integration schemes and analyzing noise propagation through dynamical systems. This work included implementation of Monte Carlo simulations for uncertainty analysis.

### Exercise 3: Sensitivity Analysis
I performed parameter sensitivity analysis on coastal hydraulic models, examining how model outputs respond to perturbations in physical parameters and boundary conditions.

### Exercise 4: Storm Surge Modeling
I developed a stochastic extension to deterministic coastal models (ADCIRC+SWAN) by incorporating additive noise into the momentum equations. This work demonstrates the application of stochastic PDEs to real-world environmental prediction, comparing stochastic and deterministic approaches against observational data.

## Software Stack

NetLogo, Vensim, LaTeX, Python, Fortran
